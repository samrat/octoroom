# Models

- `silero_vad.onnx` — Silero VAD v5, from
  <https://github.com/snakers4/silero-vad> (`src/silero_vad/data/silero_vad.onnx`),
  MIT License. SHA-256 `1a153a22f4509e292a94e67d6f9b85e8deb25b4988682b7e174c65279d8788e3`.
  Used by `Octoroom.Agent.VAD.Silero` for local barge-in detection in the cascaded backend.
- `smart-turn-v3.2-cpu.onnx` — Smart Turn v3.2 (int8, CPU), from
  <https://huggingface.co/pipecat-ai/smart-turn-v3> (revision
  `f766f81d3cfdf7737ac64aad813d91bbfd56bf93`), BSD 2-Clause License. SHA-256
  `2bb026316b14a660486a75b1733cd3fbab8c2fd0314dc9af7be49f8cca967e4f`.
  Used by `Octoroom.Agent.TurnDetection.SmartTurn` for end-of-turn detection.
- `smart_turn_features.onnx` — Whisper log-mel front end for Smart Turn
  (int16 PCM in, 80x800 features out), generated by
  `build_smart_turn_features.py`. It matches pipecat's
  `compute_whisper_log_mel_features` to within 1e-5.
